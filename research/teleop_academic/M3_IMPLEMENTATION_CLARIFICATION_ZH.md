# M3 自动候选实现前消歧

消歧内容首次记录时间：2026-08-30，早于自动候选输出的生成和观察。

版本谱系必须与内容冻结分开理解：该定义最初临时写入未提交的 M2 工作树协议，运行时协议哈希为 `9819198befc9c44e41466594e01de191ffc73f88a3f7dafae22eabbb59bdcb2c`。唯一一次 Gazebo 运行结束后，为恢复已经推送的 M2 协议哈希，才把相同定义无语义变更地迁移到本 M3 文件。原哈希已由“已推送 M2 字节 + 当时插入的消歧块”重新计算确认；用本归档协议重建的回放 CSV 也仍为运行时的 `c80e545d52ddce2e9207282e4b7f9381e14bb55b4d3d8157abbb294815e4e664`。因此，冻结先于结果的是候选定义，不是假称本文件容器在运行前已经存在。

M2 已冻结 0.5 s 窗口、逐轴物理尺度、2:1 状态进入比、迟滞、投影动作和结果阈值，但“归一化运动能量”还存在净位移或相邻增量累积两种解释。为避免看过结果后选择有利定义，M3 实现前固定为以下唯一形式。

令 \(\delta p_k=p_k-p_{k-1}\)，\(\delta\theta_k=\log(R_{k-1}^{T}R_k)\)，三个位置尺度均为 0.05 m，三个姿态尺度均为 15°：

\[
E_P(t)=\sqrt{\sum_{k:t_k\in(t-0.5,t]}\sum_{a=1}^{3}(\delta p_{k,a}/0.05)^2},\quad
E_R(t)=\sqrt{\sum_{k:t_k\in(t-0.5,t]}\sum_{a=1}^{3}(\delta\theta_{k,a}/15^\circ)^2}.
\]

- 只纳入增量结束时间位于 `(t-0.5 s, t]` 的样本；不使用未来帧。
- 窗口尚未填满时保持 UNDECIDED；两类能量均为零时也回到 UNDECIDED。
- 任务标签不参与判态，只在事后评价状态是否符合任务提示。
- 本消歧不增加能量门槛，不改变 M2 的窗口、尺度、2:1 比值、50% 串扰降低、90% 主运动保留或 0.75 s 延迟上限。

机器可读归档为 `m3_frozen_candidate_protocol.yaml`；它通过 SHA-256 继承已推送的 M2 协议，而不改写 M2 历史文件。
