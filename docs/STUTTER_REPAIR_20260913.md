# 2026-09-13 机械臂运动中急停、抖动的修复

## 直接证据

用户指定录像：`.runtime/teleop_feedback_20260913T193221_fCVL`。
在原视频 196.848、197.104、234.717 秒附近，安全指令交接触发了约一个控制周期的
`SAFETY_HOLD`，参考速度被清零后重新加速。第4关节在 234.717 秒附近的参考速度
由约159°/s降至零附近，实际速度随之下降、短暂反向，再恢复。此处输入仍然有效，
没有对应的自碰撞、关节硬限位或几何方向拒绝。

旧20 Hz诊断会漏掉约4 ms的保持；必须联合250 Hz参考和状态转换日志判断。

## 修复

- Gazebo预测轨迹和参考积分使用仿真时间，原先却按现实时间80 ms失效。
  现在以关节状态消息的仿真时间戳计算同样的80 ms运动有效期，并独立保留
  100 ms指令通信超时与250 ms状态新鲜度限制。
- 接收关节反馈不再排在几何运算后面；单独接收最新的机械臂、手指两组状态，
  在原控制线程合并、验证，再进行求解。Gazebo在同一topic分别发布这两组状态，
  不能只保留整个topic的最后一条消息，否则会丢掉其中一组。
- 本机12线程入口给安全检查和参考生成保留CPU 0–1；Gazebo和录屏使用2–7，
  相机采集2–3，HaMeR仍为8–11。其他机器不自动套用该分配。
- 每次保护状态转换立即保存诊断；记录安全速度消息和有效期。

碰撞外形、允许碰撞表、预测空间采样、关节限位、运动增益、滤波、初始姿态均未修改。
八值安全速度消息依次为六轴速度、现实通信截止时间、仿真运动截止时间；
旧六/七值接口保留。新接口限Gazebo约束控制使用。
