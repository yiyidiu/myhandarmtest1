# 新五点坐标系遥操作与回退

当前默认：**手向前（靠近相机），机械臂向前；手向上，机械臂向上。** 平移固定到机械臂基座的空间方向。按用户随后要求，手掌顺/逆时针对应的末端转向已交换：绕手 +X → 末端 −X，绕手 +Y → 末端 −Y，绕手 +Z → 末端 +Z。

前一次修改只反转绕手X控制通道的输出方向，在原来的正反向增益和限幅之后反号。`6bd8891` 保存了交换转向之前的版本，`97cbc22` 保存了本次场景调整之前的版本。

当前抓取场景：前桌沿机械臂前方移远3 cm，中心X由0.50 m改为0.53 m；左右台面由12 cm降为9 cm，桌腿相应缩短并保持落地。桌上的物体随各自台面同步调整，前桌放置标记也一起平移。横滚原配置已是3倍，继续使用手5°→末端目标15°的比例；五点坐标、平移方向、已交换的偏航方向及其余控制配置不变。

修正原因：上一版 `40a09ce` 把平移沿末端零位轴生成，而初始末端 +X 朝后、+Z 朝下，导致真人操作中的前后、上下反向。上次验证只检查了末端轴符号，没有独立检查空间前方和上方；那次结果不能作为空间同向的证据。

原代码基点为 `7d26d11`，新分支为 `codex/palm-axes-teleop-20260917`。旧腕环入口保留，切换运行模式即可回退，不需要重置 Git 或覆盖旧实验数据。

## 新坐标系及零位

使用 HaMeR 的关节点 0、5、9、13、17：原点为腕点0；Z由腕点指向四个指根均值；Y取食指根→小指根，并去除沿Z的分量后归一化；X=Y×Z。它没有乘腕环中性坐标架，也没有添加与腕环之间的角度补偿。

按 **C** 记录位置零点及相对旋转的手/末端零位。平移方向始终采用固定相机到基座的空间关系，不由按C时手或末端的朝向决定；窗口仍显示当前新手坐标轴。相机以正常正立方式放置，图像向上对应空间向上。

设按C时手和末端的旋转为 H0、E0，手腕位置为 ph0，末端位置为 pe0。位置目标在限幅前为：

`p_target = pe0 + diag(position_gain) × M × (ph-ph0)`

其中 `M = [[0,0,-1],[-1,0,0],[0,-1,0]]`：相机 −Z（向相机）→基座 +X（前），相机 −Y（图像向上）→基座 +Z（上），相机 +X（图像向右）→基座 −Y。速度前馈采用同一个M，避免位置目标和速度指令方向相反。平移限幅也在基座轴下实施。

前一次空间同向修正只改变平移映射，不改变五点建轴或旋转输入，不添加腕环姿态补偿。腕点0的公制位置沿用六组实验C的同帧可见手部深度定位方法；腕口顶点仅用于共享深度表面定位，最终控制点已移到腕点0，不使用腕环方向。

旋转输入为 `H0.T × H(t)`。沿用原控制器的 X→Y→Z 角度分解顺序，对角度施加 `(+X,-Y,+Z)` 正负关系与原增益，再组成合法旋转矩阵，并右乘在末端零位 E0 上。`diag(1,-1,1)` 的行列式为 −1，不能直接当成姿态旋转矩阵；实现没有这样做。

当前默认开启的转向交换，在上述X角完成增益与限幅后再乘−1，然后与原Y、Z角按相同顺序合成目标姿态。例：手绕X输入+10°，目标由+25.714°改为−25.714°；输入−10°，由−12.857°改为+12.857°。速度前馈对修改后的实际姿态映射求变化率，使混合旋转时的速度也与目标姿态一致。

保留原运动幅值配置：平移增益 X/Y/Z 为 1.6/1.6/1.2；旋转 X 正向约2.571倍、负向约1.286倍，Y为1倍，Z为3倍，侧转目标限制±88°。这些是目标比例，不是实际到达精度。原实时姿态平滑、输入时效检查、关节限位和自碰撞保护保留；本次改动不是新增一轮无滤波精度实验，先前A–F离线实验及数据未修改。

## 本次转向交换的仿真检查

使用带抓取物体的正式场景，确认 Gazebo 中存在 `target_object`、左右两个物体、三张工作台和机器人。输入为明确的合成左手位姿，零位的X朝相机、Y向图像右方、Z向图像上方，读取实际末端TF：

| 手部输入 | 本次末端实际旋转（相对末端零位X） |
|---|---:|
| 绕手+X转12.61°（画面逆时针） | −30.72° |
| 绕手−X转12.61°（画面顺时针） | +15.33° |

两侧分别按原正反向增益响应，输出方向已交换。相同序列同时观测到：向前25 mm输入产生向前37.59 mm，向上25 mm输入产生向上28.22 mm；手+Y仍对应末端−Y，手+Z仍对应末端+Z。原始记录见 `gazebo_reversed_turn_grasp_result.json`。

这是仿真中的方向检查，不是新的真人视觉精度实验，也没有声称已完成真人抓取。速度限幅和短暂保持使实际角度小于目标角度；原目标增益、±88°侧转限幅及输入相同时的其他目标分量另由定向回归检查核对。

## 历史验证：空间同向修正（6bd8891，尚未交换转向）

方向回归检查使用独立预期：手向相机必须得到基座+X目标，手在图像中向上必须得到基座+Z目标；包括默认朝后/朝下的末端零位、倾斜手零位、倾斜末端零位及正反向输入。同时核对位置与速度方向一致、原绕轴旋转不变。

在独立的 Gazebo 实例中用正式控制器和修正后的映射，输入明确的合成手位姿，读取实际仿真末端 TF。平移的预期方向固定为基座前、侧、上，不再用末端零位旋转预期方向。结果如下：

| 测试输入 | 预期运动方向 | 仿真实际沿该方向变化 |
|---|---|---:|
| 手向相机平移25 mm | 机械臂向前（基座+X） | 37.59 mm |
| 手在图像中向左25 mm | 基座+Y | 37.80 mm |
| 手在图像中向上25 mm | 机械臂向上（基座+Z） | 28.25 mm |
| 手绕 +X 转12.61° | 末端绕 +X | 30.70° |
| 手绕 +Y 转12.61° | 末端绕 −Y | 11.93° |
| 手绕 +Z 转12.61° | 末端绕 +Z | 35.85° |

每次动作均接反向返回；最终距离开始位置约0.257 mm。前向平移的非目标轴位移约0.296 mm，上移的非目标轴位移约0.052 mm。原有增益、速度限制和有限保持时间使实际运动量与目标量有差异。修正后的原始结果见 `gazebo_spatial_direction_result.json`。这些数值只说明本次合成输入驱动的仿真运动；不是视觉测量精度、真人跟随精度或实物机械臂结果。

还用一帧真实 RGB-D 回放经过 HaMeR、新五点建轴、公制位置打包和正式窗口绘制代码，核对新坐标系与显示一致。真人在线效果由上述新版命令运行观察；尚未把合成输入验证当作真人跟随验收。
