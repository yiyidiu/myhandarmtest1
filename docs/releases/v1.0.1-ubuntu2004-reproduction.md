# v1.0.1 · Ubuntu 20.04 快速复现包

这是 `v1.0.0-clean-baseline` 之后的可移植性版本，不改变机器人控制算法。

## 新增

- Ubuntu 20.04 / ROS Noetic 一键依赖安装、构建和测试入口：`scripts/bootstrap_ubuntu2004.sh`；
- 面向 GitHub 新手的下载、SHA-256 校验、解压和运行说明；
- 对 HaMeR/MANO 大模型、D455、CUDA 和实体硬件边界的明确提示。
- 完整测试重新盘点为 439 项唯一测试，并移除测试入口中一次重复的 79 项调用。

## 验收口径

- Ubuntu 20.04 amd64；
- ROS Noetic；
- 六个 Catkin 包 Release 构建；
