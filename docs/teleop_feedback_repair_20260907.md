## 操作语义的变化

保护阻止运动时丢弃未执行目标，会改变当前的人手机械臂对应关系。保护触发后，人手回到原来的位置或角度，机械臂不保证回到最初按 C 的位姿；再次按 C 会重新对齐。该行为用于减少反向时消耗积累误差的等待，是否符合实际操作习惯仍需体验确认。

没有采用手动平移/旋转模式切换，也没有把姿态长期冻结。小幅三轴平移及三轴旋转都已通过真实 Gazebo 运动检查。旋转映射倍率仍为 1，尚未宣称解决旋转舒适性。
