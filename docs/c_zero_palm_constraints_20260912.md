# C后静止保护与真实掌面深度约束验证

当前优先结果是：按C后手基本不动时，机器人目标保持标定位置与姿态；开始明确运动后按原比例跟随。平移及单轴转动的串动需要继续处理，本轮没有把它们标为解决。

## C后自发变化：本轮实际修复

输入来自最新已有的 `hand_motion_observation_20260911T202058_Ime9`。该记录没有更新，本次没有启动相机或新采集IMU；也没有做抓取验收。

此前已保护首次姿态，但位置通道仍将C后约1.3–3.2毫米的手部估计波动作为新目标发送。C后的短静止片段重新送入当前Gazebo时，末端实际移动约1.68毫米。第一帧C绑定并没有错，问题发生在后续小幅位置波动进入映射之后。

现在增加独立的首次位置保护：

- C成功后，距离原手C位置不超过4毫米时，发送的位置保持在C。
- 连续三个不同的新观测超过4毫米，解除首次位置保护，并传递完整位移；不减去4毫米，也不移动手C或机器人C。
- 解除后，返回C附近也不会重新启用这项首次保护，后续小幅定位仍用原映射。
- 位置与姿态分别判断，主动旋转不必等待平移。原有小角度旋转增益不变，原有首次姿态静止保护继续使用。

4毫米是针对已观察到的约3.2毫米初始位置波动选用的工程阈值，不是传感器精度保证。**代价是C后第一次不足4毫米的位移暂不响应。** 本次数据首次超过阈值是66.237秒，第三个新观测为66.404秒，放行确认额外等待约0.167秒。移动开始后的微调没有这项新限制。不能将该处理说成无代价地识别了所有真实微动。

相同初始姿态、同一批记录位置与已修正姿态、相同接收时序的空场景Gazebo对照，仅改变首次位置保护：

| 结果 | 修改前 | 修改后 |
|---|---:|---:|
| C静止段目标相对C的最大位置变化 | 2.59毫米 | 0 |
| C静止段实际末端相对C的最大位置变化 | 1.68毫米 | 0.24毫米 |
| C静止段实际末端最大转角 | 0.059° | 0.061° |
| 明确运动片段最终跟随位置误差 | 2.44毫米 | 2.02毫米 |
| 单独给入5°横滚后的实际末端转角 | 14.95° | 14.96° |

实际末端仍有约0.24毫米与0.06°残差，因此不能宣称物理仿真绝对不动。C的目标位置和姿态保持不变已经在此片段得到验证，真人当前使用感受尚未复测。

回放使用65.303–66.071秒的真实初始观测，随后额外保持最后一个观测0.8秒，观察机械臂延迟响应，再回放已有的明确移动片段。5°横滚是另一个明确的合成输入，用于检查原有比例，不是真人视觉准确性验收。

## 密集掌面深度约束：已验证但未接入控制

本轮直接使用原始深度，取腕部与四个掌指根包围区域的内部70%，排除手指及轮廓边缘。每帧约数百个有效表面点，独立拟合掌面方向；拟合不使用HaMeR姿态、IMU姿态或前一帧方向。IMU只用于事后比较。

| 片段 | 深度掌面方向最大变化 | IMU三维总转角 |
|---|---:|---:|
| 初始静止附近 | 4.71° | 0.88° |
| 左移 | 13.43° | 9.23° |
| 再次左移 | 17.96° | 12.65° |
| 主动俯仰 | 59.10° | 53.34° |
| 主动横滚 | 40.84° | 46.20° |

这里两列不是同一种完整姿态量：刚性掌面方向的变化不能超过其完整刚体转角，但可以小于完整转角。例如绕掌面法线旋转时，法线几乎不动。因而不能把两列接近当作逐轴准确，也不能把法线变化更小直接判为漏掉真实转动。

静止附近约479个表面像素、平面深度拟合残差中位数约0.89毫米，仍出现4.71°方向变化。固定同一个像素取样区域后，仍约4.70°；这排除了“主要由取样区域跳动引起”的简单解释，但尚不能在原始深度噪声、掌面曲率和轻微形变之间做唯一归因。

这些数据不支持直接用当前深度法线纠正几度的微小转动。**没有接入固定视角补偿，没有新增深度姿态融合，没有冻结平移过程中的旋转，没有更改旋转增益，也没有调整机器人控制器和碰撞限制。** 上一轮经验视角补偿、有限位置让步的试验开关继续默认关闭。

下一次深度方向纠正实验首先需要足以分辨小角度运动的独立观测；现有数据在这一步还没有达标。不再用更长的平滑或更多参数把这个缺口包装成“姿态已经正确”，也不会把IMU总转角拟合成逐轴真值。本轮先交付已验证的C修复。
