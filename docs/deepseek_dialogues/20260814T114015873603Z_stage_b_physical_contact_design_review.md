# Stage B（真实物理抓取）设计审查

## 1. SUMMARY

核心问题——**现有 SetPosition mimic 必须在物理基线之前替换**。逐仿真步 `SetPosition` 是运动学瞬移：零柔顺、无视接触动力学，等价于每个时间步把关节钉死，可穿透接触或向物体注入能量；即便抓取成功，证据也无法排除"被钳制"而非"被真实接触力握持"。这违反"无强制位姿"的物理诚实性原则。Mimic **耦合本身**（连杆/腱式速比约束）可以保留，但必须通过带 PID 的有限力驱动实现，使接触力成为因果可查的物理量。

其余设计（双世界隔离、负向测试门禁、≥2 指接触、0.08 m 抬升、2 s 保持、开手掉落）方向正确，短板在：无指腹接触传感器导致接触证据只能靠力矩间接推断；CLOSE 一步发最大角无中间监控；0.10 kg 轻盒极易被接触求解器参数（min_depth/kc/kd 粘滞）造假稳定。

## 2. ASSUMPTIONS

- 物理世界重力常开，盒体非 static，其摩擦/惯量已按公开值配置。
- "旧固定附件插件仅服务调用时连接"仅指其 ROS 服务接口惰性存在；评审假设其 Gazebo 侧无隐式连接（需以世界加载日志与 `/services` 列表验证）。
- 手指关节为 revolute，STL collision 网格几何合法；mimic 为纯速比耦合（无摩擦、无传动弹性建模）。
- 抬升动作由 IRB120 手臂执行，手部整体随手臂平移；相对漂移以"盒体 vs 手掌坐标系"度量。
- 未假设接触传感器已存在——当前无，须新增或改用间接证据。

## 3. 最高风险（8 项）

1. **[物理] SetPosition 能量注入/穿透**：每步 teleport 产生无穷刚度假象；接触瞬间可把物体推出、压穿或维持无接触力钳制。任何基于当前 mimic 的基线都不可作为物理证据，必须先替换。
2. **[物理] 轻盒粘滞假稳定**：0.10 kg 盒 + Gazebo 默认 `min_depth`/接触 kc,kd 下，单指或指尖微接触都可能"粘"住盒体，导致负向测试 3/4 误通过；必须标定 solver 参数并让开手掉落测试明确失败路径。
3. **[证据] 无指腹接触传感器**：三指各缺独立 contact sensor，接触成立只能靠关节力矩/位置停滞间接推断，无法区分"真实接触"与"位置饱和/摩擦自锁"；至少须在指尖加 Gazebo contact sensor（纯传感、不改碰撞物理）。
4. **[控制] 一步 CLOSE 最大角**：无逐步闭合，无每步接触评估，无法实现"接触即停"的力控制语义；还制造高速冲击，可能击飞轻盒。必须改增量/限速闭合状态机。
5. **[架构] 双世界隔离未验证**：旧插件若在 physical_contact 世界中被任何依赖链加载，全部抓取统计作废；须机检：加载日志、`/services` 清单、`allow_nonphysical_attachment` 标志缺失时启动即失败。
6. **[语义] 位置控制抓取的力界限**：即便换 PID，纯位置闭环在接触稳态下会持续积分逼近，形成钳紧力；必须设 PID 增益上限与每指目标停滞判定，保证抓持力有限、可复现。
7. **[判定] 相对漂移阈值未定义**：0.08 m/2 s 判据成立，但"漂移受限"无数值；须在统计前定义（建议：抬升+保持全程平移漂移 ≤5 mm、旋转 ≤3°，以手掌系为参考，具体值由无接触标定实验校准后写死）。
8. **[实验] 负向测试为软门槛风险**：负向测试若与统计同参数、同环境跑且失败只"记录"不阻断，等于没有门槛；必须硬门禁：任一负向测试未通过 → 禁止进入统计。

## 4. 最小改造顺序

1. **世界隔离（先做，零物理风险）**：把旧插件从 physical_contact 世界移出；新建 `fixed_attachment_demo_nonphysical` 世界并更名插件，缺省 `allow_nonphysical_attachment=false`，显式 true 才启动；physical_contact 世界加载时验证无该插件进程/服务/话题。
2. **替换 mimic 驱动（基线前置条件）**：4 个 mimic 关节从 SetPosition 改为**有 PID 的主动位置关节**，目标 = leader 关节位 × mimic 速比（比例可负）；PID 用保守低增益（低 kp、有限 ki、有限输出限幅），使接触稳态力有限。物理上这是"耦合+弹性驱动"近似，不是固定关节、不夸张碰撞、不动 STL。
3. **碰撞/求解器标定**：保持 STL 原样（严禁放大指尖）；只调 `min_depth`、接触 kc/kd、最大接触点，以负向测试 1/2 无粘滞为准。
4. **接触证据通道**：三指指尖加 Gazebo contact sensor（link 级接触传感器，不改动力学）；关节力矩停滞 + 目标/实际位置偏差作为第二通道交叉验证。若拒绝加传感器，则书面声明证据降级并只允许力矩判据的最保守形式。
5. **逐步闭合状态机**（见 §5）。
6. **负向测试门禁**（见 §6）→ 全部通过才开放统计。
7. **统计协议**：定义 N（建议 ≥10 run）、每 run 记录接触帧、指力矩、闭合步数、抬升/保持漂移曲线、掉落时程；每失败 run 分类归因。

## 5. 接触传感与闭合状态机

**接触证据（每指）**：
- 主通道：指尖 contact sensor 提供接触法向/位置；
- 次通道：该指 PID 力矩增长 + 实际位置停滞（误差收敛但力矩上升）；
- 判定"稳定接触"：接触持续 ≥200 ms、法向偏离指尖法线锥内、力矩不振荡发散。

**闭合状态机（增量、限速）**：
1. 初始：四主动关节回张开位；每指目标按小增量下发（如 ≤1°/步，周期 20–50 Hz，等价关节速度限幅）。
2. 每步评估三指接触状态；某指达到稳定接触 → 该指目标冻结（不再前进），其余指继续。
3. 终止条件：≥2 指稳定接触，且未接触指再前进也不会改善（防单侧夹紧）；超时/超步数 → 本次 run 计失败。
4. 握持冻结期：所有手指目标保持，采样 0.5 s 验证接触不丢、盒体相对手掌无漂移，作为抬升前基线。
5. 抬升：手臂抬 0.08 m；全程记录盒体相对手掌位姿漂移曲线；抬升结束进入 2 s 保持期继续记录。
6. 释放：OPEN 全开（同样增量下发），盒体须在重力下自然下落；掉落时程与自由落体一致性校验（下落加速度方向向下、无向上初速尖峰）。

## 6. 负向测试（统计前硬门禁，四项全过才开统计）

1. **张手抬升**：手指全开，掌心自盒顶上方下降至接近但不接触，再抬起 → 盒体不得被吸附/提升。
2. **无接触横移**：手在盒旁无接触横向移动 → 盒体不得被拖动/吹动（检验 mimic 残留能量注入与求解器伪力）。
3. **打开掉落**：完成一次握持后 OPEN → 盒体必须在无附加约束下自由下落，时程与自由落体一致（检验无隐性附着）。
4. **单指不得成功**：仅允许一指闭合（其余锁定张开）执行完整闭合+抬升流程 → 必须失败（滑脱/无法抬升）。若单指竟抬升 0.08 m，判定求解器粘滞造假，回 §4.3 标定后重测。

**附加探针（建议并入负向批次）**：手指冻结于握持位但不接触盒，盒体静置于桌面 → 观测 2 s 内盒体位移必须 < 1 mm（能量注入探针）。

## 7. 通过/失败判据

**单次 run 成功（全部满足）**：
- 无固定关节、无 LinkAttacher、无强制位姿；physical_contact 世界内无任何 attachment 插件。
- 闭合过程 ≥2 指稳定接触，接触证据为主通道（sensor）+ 次通道（力矩）一致。
- 真实抬升：盒体重心升高 ≥0.08 m（以手掌系或世界系双记录）。
- 保持 ≥2.0 s，期间相对漂移 ≤ 校准阈值（建议初值 5 mm/3°，必须由负向测试前的标定实验定值并写死）。
- OPEN 后自然掉落，无附着、无向上冲量。

**统计判据（开跑前写死）**：N≥10，成功率 ≥80%（建议），每次失败逐 run 归因；任何一次成功被证明由非物理因素造成 → 整批作废并回炉。负向测试四项全部通过为前置条件，不满足即禁止统计。
